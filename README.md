# Money Savings App

A simple personal money tracker built with Unity. Manually add money to your balance when you receive it and subtract money when you spend it.

## Features

- Add money to your balance manually.
- Record spending and subtract it from your balance.
- Track how much money you use each day.
- View a history of money added and taken out, including when each transaction happened.
- Add a description to each deposit or expense so you can remember what it was for.

## How to use

1. Enter money you receive to add it to your balance.
2. When you spend money, enter the amount to subtract and add a description.
3. Check the daily usage tracker and transaction history to review your spending.

## Open the project

Clone or download this repository, then add the project folder in Unity Hub. Open it with Unity **6000.2.6f2**, the version recorded in `ProjectSettings/ProjectVersion.txt`.
